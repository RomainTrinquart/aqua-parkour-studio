Parcours et points de passage

Déplace les lignes via ⋮⋮ ou avec les flèches. En mode participant, clique sur une plateforme, une prise jaune ou directement sur l’eau pour ajouter un point. Barre maximale : 2,35 m.

Déplacer le point dans l’espace

Sélectionne un point, puis glisse les flèches rouge (X), verte (Y), bleue (Z). Sur iPhone, utilise ton doigt.

Éditer le passage sélectionné

Chaque mouvement relie le passage précédent à celui-ci. Clique sur une zone précise d'un module pour placer un nouveau point.
